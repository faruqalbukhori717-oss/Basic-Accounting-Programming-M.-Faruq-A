This Page is Responsive!

Try resizing your browser window or use the responsive mode in Developer Tools (Ctrl+Shift+I or F12).

You will see changes in background color and text size when the screen width crosses a certain limit.

Example Code responsive_text_styles.css: body { font-family: Arial, sans-serif; margin: 20px; background-color: lightblue; /* Default color for wide screens */ color: #333; text-align: center; } h1 { font-size: 2.5em; color: navy; } p { font-size: 1em; line-height: 1.5; } /* Media Query for screens with a maximum width of 600px (e.g., mobile phones) */ @media screen and (max-width: 600px) { body { background-color: lightcoral; /* Color for small screens */ color: white; } h1 { font-size: 1.8em; /* Smaller font size on small screens */ color: darkred; } p { font-size: 0.9em; } }
